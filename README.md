# سيرفر التحكم المركزي — هايبر ماركت الشرقاوي

سيرفر واحد بيعمل 3 حاجات:
1. **إصدار وإدارة تراخيص شاشة الأسعار** (بديل أقوى لأداة "مولد-التراخيص.html" المحلية — ده بقى أونلاين ومركزي، ويقدر يلغي أي ترخيص فورًا).
2. **لوحة تحكم ويب** (`/`) — تفتحها من أي جهاز أو موبايل، فيها تسجيل دخول بباسورد.
3. **نظام توزيع تحديثات** لتطبيقات ويندوز والأندرويد.

---

## 1) تجربته على جهازك الأول (قبل رفعه أونلاين)

يحتاج [Node.js](https://nodejs.org) نسخة 18 أو أحدث.

```bash
cd server-app
npm install
cp .env.example .env
```

افتحي ملف `.env` واملي:
- `ADMIN_USERNAME` — اسم دخولك للوحة التحكم
- `ADMIN_PASSWORD_HASH` — شغّلي الأمر ده وحطي الناتج:
  ```bash
  node scripts/hash-password.js "كلمة-السر-اللي-عايزاها"
  ```
- `JWT_SECRET` — أي نص عشوائي طويل (يعني مفتاح داخلي للسيرفر، مش لازم تفتكريه)
- `LICENSE_SECRET` — **سيبها زي ما هي** إلا لو قررتي تغيّريها في كل الأماكن التلاتة (شوفي قسم "تحذير مهم" تحت)

بعد كده:
```bash
npm start
```

هيقولك `✅ سيرفر التحكم شغال على المنفذ 3000`. افتحي `http://localhost:3000` في المتصفح وسجّلي دخول.

---

## 2) رفعه أونلاين (يفضل شغال 24 ساعة)

### الطريقة الأسهل: Railway
1. اعملي حساب على [railway.app](https://railway.app) (فيه باقة مجانية للتجربة)
2. من الداشبورد: "New Project" → "Deploy from GitHub repo" (لازم ترفعي المجلد ده على GitHub الأول)، أو "Empty Project" وبعدين اربطيه بالكود
3. ضيفي متغيرات البيئة (نفس اللي في `.env`) من تبويب **Variables**
4. Railway هيدّيكي رابط تلقائي زي `your-app.up.railway.app` — ده رابط لوحة التحكم بتاعتك، واللي تحطيه في التطبيقات كمان

### البديل: VPS (تحكم كامل، محتاج خبرة أوامر Linux)
لو عايزة السيطرة الكاملة (DigitalOcean, Hetzner...):
```bash
# على السيرفر بعد تنصيب Node.js:
git clone <رابط المشروع بتاعك> && cd server-app
npm install --production
cp .env.example .env   # واملي القيم زي فوق
npm install -g pm2
pm2 start server.js --name sharqawy-server
pm2 startup && pm2 save   # يشتغل تلقائي لما السيرفر يعيد تشغيل
```
يفضّل تحطي [Nginx](https://nginx.org) قدام السيرفر مع شهادة HTTPS مجانية من [Let's Encrypt](https://letsencrypt.org) — لو عايزة أساعدك في الخطوة دي بعدين قولّيلي.

---

## 3) ⚠️ تحذير مهم — LICENSE_SECRET

القيمة دي لازم تكون **متطابقة تمامًا** في 4 أماكن:
1. هنا في `.env` (`LICENSE_SECRET`)
2. `مولد-التراخيص.html`
3. `شاشة-استعلام-الأسعار.html` (وتطبيق ويندوز Electron المبني منها)
4. تطبيق الأندرويد (لما نجهزه)

لو غيّرتيها في مكان وسبتيها في الباقي، أي مفتاح ترخيص هيبقى "غير صالح" في الأماكن اللي معندهاش نفس القيمة. الأفضل تسيبيها زي ما هي دلوقتي.

---

## 4) إيه اللي لسه ناقص (الخطوات الجاية)

- **ربط تطبيق ويندوز (Electron) بالسيرفر ده**: دلوقتي التطبيق بيتحقق من الترخيص محليًا بس. الخطوة الجاية إننا نخليه كل شوية يسأل السيرفر "لسه الترخيص ده سليم؟" — وده اللي هيدّيكي قدرة إلغاء ترخيص أي جهاز فورًا، ومتابعة آخر مرة كل جهاز فتح البرنامج.
- **نظام التحديث التلقائي (auto-update)**: السيرفر جاهز لاستقبال ونشر النسخ (تقدري تجربيه دلوقتي من تاب "التحديثات")، لكن لسه محتاجين نضيف الكود في تطبيق ويندوز اللي بيسأل "فيه نسخة أحدث؟" وينزّلها لوحده.
- **تطبيق الأندرويد**: لسه معملناهوش.

هكمل في التلات نقط دول تباعًا.

## هيكل المشروع

```
server-app/
  server.js       ← نقطة البداية، كل الـ API endpoints
  db.js           ← قاعدة بيانات SQLite (ملف واحد، بيتعمل تلقائيًا)
  license.js      ← توليد والتحقق من مفاتيح التراخيص
  public/         ← لوحة التحكم (الواجهة اللي بتفتحيها في المتصفح)
  scripts/        ← أداة توليد هاش الباسورد
  data/           ← قاعدة البيانات بتتخزن هنا (متتمسحش بعد النشر!)
  updates/        ← ملفات exe/apk المرفوعة بتتخزن هنا (متتمسحش بعد النشر!)
```

**تنويه:** مجلدي `data/` و `updates/` هما "ذاكرة" السيرفر — فيهم كل التراخيص والتحديثات. لو بتستخدمي استضافة زي Railway، تأكدي إنك مفعّلة خاصية **Volume/Persistent Storage** عشان المجلدين دول ميتمسحوش كل ما السيرفر يعيد تشغيل نفسه (ده بيحصل تلقائيًا كل فترة في أغلب الاستضافات المجانية).
